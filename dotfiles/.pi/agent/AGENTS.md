# Global Agent Context

## GitHub Access

Always use the `gh` CLI to access github.com links (issues, PRs, repos, etc.) since many links will be to private repositories. Examples:

- `gh issue view <url>` - View issue details
- `gh pr view <url>` - View PR details  
- `gh pr diff <url>` - View PR diff
- `gh api <endpoint>` - For other API access
- `gh browse -n <url>` - Get repo info
